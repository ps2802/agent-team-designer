# Preferences: the intake

Ask all of these in one numbered message, with the default in brackets. Skip any the request already answers.

1. **The workflow:** what should this team get done, and what does it look like today? [describe one recurring workflow]
2. **Who's involved:** just you, or a team? Names and roles if a team. [just me]
3. **Autonomy:** how much should agents do without asking? [draft and prepare; a person approves anything irreversible]
4. **Always human:** which decisions must stay with a person? [money, production changes, anything sent to customers]
5. **Tools and models:** which agents, models and tools do you already use? [Claude Code + the tools you name]
6. **Data boundaries:** what must never leave where it lives (code, keys, customer data)? [secrets and customer data]
7. **Budget:** any limit on spend per run or per month? [keep it lean; flag anything costly]
8. **Speed vs quality:** if they trade off, which wins? [quality on anything external, speed internally]
9. **Output depth:** one-pager, full blueprint, or ready-to-use build files? [blueprint]
10. **Success:** how will you know in a week that this worked? [time saved on the workflow, fewer hand-off misses]
